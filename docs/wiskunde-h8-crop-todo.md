# H8 — nog te croppen figuren (nakijkbare opgaven)

Deze H8-opgaven hebben een **figuur nodig** maar wél een schoon boek-antwoord
(oppervlakte/omtrek met letters). Ralph cropt de figuren later met de croptool
(`npm run croptool`, type **nakijk**); daarna koppel ik het boek-antwoord en maken
we er nakijkbare Cat-2-opgaven van.

**Werkwijze:** open de croptool in Chrome/Edge → foto-map = `content/2026-t3/raw/wiskunde/`
→ blader naar de juiste `wiskunde-h08-pNNN`-pagina → kader om de figuur → opgavenummer
invullen → type **nakijk** → opslaan. De tool zet hoofdstuk + sectie automatisch goed.

Verwachte bestandsnaam = `h8-<sectie>-opg<nr>-nakijk.jpg`. Sla op in
`content/2026-t3/assets/wiskunde/h8/` (de image-loader pakt elke submap onder
`assets/wiskunde/`). Stuur me daarna gewoon "H8-figuren staan in de map".
